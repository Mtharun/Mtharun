I'm a Full Stack Web Developer (MERN) based in Salem, India, building full-stack apps end to end — auth systems, REST APIs, React dashboards — and shipping every one of them to a live URL instead of stopping at "it works on my machine." Since 2023 I've been building at **GUVI**, and I've recently been extending into AI-integrated products using the **Claude API**.
